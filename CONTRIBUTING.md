# Contributing to Awesome Production AI Stacks

Thanks for helping document production-grade AI architectures.

## What belongs here
This repo is about **stacks (architectures)** — not tool lists.

A good submission includes:
- The **problem** the stack solves
- The **end-to-end architecture**
- **Why** each major component was chosen
- **Failure modes** and tradeoffs
- A **confidence level**:
  - 🔍 Confirmed (public sources)
  - 🧠 Inferred (strong signals + reasoning)
  - 🧪 Reference (recommended blueprint)

## What will be rejected
- Pure tool directories
- Affiliate spam
- “Just launched” demos with no operational maturity
- Marketing copy without implementation detail

## How to submit a stack
1. Fork the repo
2. Copy the template: `stacks/_TEMPLATE.stack.md`
3. Add your stack under the right category folder (e.g., `stacks/product/`)
4. Open a Pull Request

## Stack format requirements
Your stack **must** include:
- Use case + scope
- Architecture (components + flow)
- Implementation notes
- Eval/monitoring approach
- Failure modes
- Sources (if Confirmed)

## Corrections
If you see an error, open an issue using “Correction report” and include supporting links.

Quality > quantity. Trust is the product.
